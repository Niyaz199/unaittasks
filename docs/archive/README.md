# Архив документации

Документы в этом каталоге — завершённые планы, baseline-заметки и наброски дизайна, оставленные для исторической справки. Они не актуализируются и могут противоречить текущей реализации. Для актуальной документации смотри `docs/` и `docs/user-guide/`.

## Что здесь лежит

- `PHASE_0_BASELINE.md` — замер состояния проекта до начала крупных доработок.
- `AUDIT_REMEDIATION_PLAN.md` — план по закрытию замечаний аудита (выполнен).
- `PPR_DEVELOPMENT_PLAN.md`, `PPR_EXECUTION_BATCHES.md`, `PPR_IMPLEMENTATION_BLUEPRINT.md`, `PPR_DB_MIGRATIONS_PLAN.md` — разбиение реализации модуля ППР на этапы и миграции (модуль реализован).
- `warehouse-items-redesign.md` — замысел редизайна каталога ТМЦ (реализован).
- `ДизайнКаелндаря.md`, `Календарь.md` — ранние наброски календаря ППР.
