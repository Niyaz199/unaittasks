# Smoke / E2E

Минимальный `Playwright`-набор для шага `10.1`.

## Установка

```bash
npm run test:e2e:install
```

## Запуск

```bash
npm run test:e2e
```

Для локальной отладки:

```bash
npm run test:e2e:headed
```

По умолчанию `Playwright` поднимает локальный `Next dev` на `http://127.0.0.1:3001`.
Если сервер уже поднят вручную, конфиг его переиспользует.

## Обязательные env для auth-сценариев

- `E2E_EMAIL`
- `E2E_PASSWORD`

## Дополнительные env для data-driven smoke

- `E2E_ROUNDS_OBJECT_NAME` — имя объекта для smoke-конфига обходов
- `E2E_ROUNDS_ROOM_NAME` — имя помещения, которое можно безопасно переключить и вернуть обратно
- `E2E_ROUNDS_TOKEN` — валидный QR token помещения, доступный текущему пользователю
- `E2E_PPR_TASK_ID` — доступная ППР-заявка, к которой пользователь может добавить комментарий
- `E2E_PPR_CALENDAR_SYSTEM_NAME` — доступная система для smoke-генерации месяца

Если часть env не задана, соответствующие тесты будут пропущены, а остальной минимальный набор продолжит выполняться.
